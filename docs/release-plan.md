# Release plan

This project is a development prototype and should not be published as a real mod until it has a tested build.

## Release rule
- `design/` = concept and planning
- `mod/` = actual runtime files when built
- `release/` = final packaged build once tested

## Versioning
- `v0.1.0-alpha` = first public concept release only
- `v0.2.0` = first working mod prototype
- `v0.3.0` = tested gameplay slice

## Required before any Melty listing
- The player can launch the game in one click
- The required host game is clearly identified
- A real screenshot or clip exists
- The project is verified to run in the host game
- Credits and license are explicit
