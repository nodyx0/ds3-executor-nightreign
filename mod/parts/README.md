# Armor and Weapon Parts Folder

This folder holds weapon and armor asset files.

For v0.1, this folder is EMPTY.

DS3 will use the default weapon and armor models from your chosen loadout.

The Executor appearance comes from:
- Pontiff's Curved Sword (existing DS3 weapon)
- Assassin Garb (existing DS3 armor)
- Dark color theme

If you later want custom armor/weapon appearance, asset files would go here.
